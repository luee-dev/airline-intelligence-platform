# Airline Network & Revenue Intelligence Platform

**An end-to-end analytics and data science platform for airline network
profitability, demand, operations and customer strategy, built on 100% simulated data.**

> This project is **not affiliated with, endorsed by, or built on data from any real airline**. 
Every record — flights, bookings, customers, delays, costs - 
is synthetically generated by 
[`src/data_generation/generate_data.py`](src/data_generation/generate_data.py) 
with a fixed random seed. 
It is inspired by publicly known airline business dynamics (hub-and-spoke networks, seasonality, 
load factors, cost structure) purely to give the platform a realistic problem to solve.

The platform ingests transactional and operational data, runs automated data-quality
auditing, computes business KPIS through a SQL analytical layer, and layers
statistical/ML models on top for demand forecasting, delay-risk classifications, 
customer segmentation and price-elasticity estimation.
Then translate all of it into a specific business recommendation, not just a metric.


---

## Why this exists

This project is built to demonstrate the full chain a real analytics function is judged on:

```
business question → clean, trustworthy data → SQL/BI answer → statistical/ML model → a recommendation someone could actually act on
```

## Quickstart (5 minutes, zero cloud account needed)
```bash
# 1. Clone and set up a virtual environment
git clone https://github.com/luee-dev/airline-intelligence-platform.git
cd airline-intelligence-platform
python -m venv .venv && source .venv/bin/activate # Windows: .venv\Scripts\activate
pip install -r requirments.txt

# 2. Generate the simulated dataset (reproducible, ~15s for 3 months of data)
python src/data_generation/generate_data.py --start 2024-01-01 --end 2024-03-31 --customers 15000

```
